## Janice

This is my collection of Jenkins plugins for AI code review and automating tasks. Here's a list of the plugins in here.

# Jenkins AI Synapse
A base plugin providing a singular API interface for all the different model providers

# Jenkins Ollama Client
Implements an AI synapse client for Ollama

# Jenkins OpenAI client
Implements an AI synapse client for OpenAI

# Jenkins Anthropic client
Implements an AI synapse client for Anthropic

# Jenkins Gemini Client
Implements an AI synapse client for Gemini

# Github Commentor
A plugin with some simple steps to perform CRUD operations on github comments for issues, pull requests and commits.

# JenkinsOCR
A plugin to provide an OCR scanning automation which lets you upload images of notes and other documents to Jenkins which will then use an AI model to scan the text and upload it to a notion page. It serves as a first test case for Jenkins AI Synapse while being helpful for me to be able to scan homework and notes so I can search them easily when studying for classes.
